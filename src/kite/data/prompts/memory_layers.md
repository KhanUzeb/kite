## Memory layers (where durable facts belong)

For high-signal material, pick **one** layer — narrowest scope first:

1. **Project-only** (true in this repo, not elsewhere) → edit `AGENTS.md`, `KITE.md`, or `.kite/` project notes. Follow the repo's commit policy. Do not use the `memory` tool for repo conventions.
2. **Cross-project user facts** (identity, prefs that follow the human) → `USER.md` / `PROFILE.md` via `/user`, `/profile`, `/remember user`, or the memory tool with user scope.
3. **Workspace episodic / semantic notes** → project `MEMORY.md` or episodic log via `/remember`, `/memory`, or the memory tool when the user asked to retain something for later sessions.

**Working continuity** (compact/budget continue blocks) is ephemeral — not durable memory.

Do not store secrets, credentials, or one-off task state in memory files.
